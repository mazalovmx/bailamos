# Ход реализации

## Начальный setup
- Монорепозиторий pnpm: web (Next.js 15 / React 19), admin (Refine), db (Prisma 6).
- Next.js зафиксирован на 15.5.27 из npm; версия из ветки ТЗ.
- PostgreSQL 17 / PostGIS 3.5 и Redis 7.2 — локальный Compose, порты только на loopback. MinIO вынесен в необязательный профиль storage: оба официальных registry отказали в скачивании. S3-хранилище пока не работает.
- Prisma 6 оставлен для простого совместимого подключения PostgreSQL; переход на другую major требует отдельного решения.
- Базовая доменная схема с FK, индексами, UTC timestamptz и IANA timezone.
- geo вычисляется триггером из lat/lng, GiST создаётся SQL-миграцией.
- Стили событий нормализованы в EventStyle вместо массива строк: целостность обеспечивается FK.
- Английский язык по умолчанию, маршруты /en, /es, /ru. Переключатель виден в шапке главной страницы; автоматическое определение языка браузера отключено.
- Refine подключён без доступа к данным: административные роли и рабочие экраны остаются E9.
- PWA: пока только manifest и SVG icon. Offline, PNG icons, push и проверка установки остаются E10.
- Seed расширен свинговыми направлениями: Lindy Hop, Solo Jazz, Balboa, Shag, Charleston и подстили. Существующие несвинговые записи сохранены.
- Better Auth: аккаунты, сессии, подтверждение почты, reset, возрастное подтверждение и rate limit в БД. Mailpit перехватывает локальные письма.
- Профиль связан с владельцем; текущая форма хранит один основной навык. Поиск партнёра остаётся выключенным.
- Рабочий REST API проверяет сессию, подтверждение почты, origin, Zod-ввод и права CASL. UI на Next.js, данные в Prisma/PostgreSQL.
- События: черновик, публикация, редактирование, отмена, RSVP, личный список и публичная афиша.
- События получили тип, формат, уровень, нагрузку, темп, теги и требования. См. swing-model.md.
- RRULE WEEKLY с COUNT 2–52 материализуется в EventOccurrence. Даты рассчитываются в IANA-зоне города; неоднозначные/несуществующие времена отвергаются.
- Афиша показывает отдельные даты серии; RSVP пока на всю серию. Индивидуальные отмены/переносы и запись на отдельный урок пока отсутствуют.
