## Отступления от ТЗ

- REST вместо tRPC — продолжение существующего кода.
- Полнотекст PostgreSQL вместо Meilisearch и чат в монолите вместо Matrix — обе замены разрешены ТЗ.
- Локальные медиа пишутся на диск (`.data/media`); S3 включается переменными `S3_*`. Образ MinIO скачать не удалось.

## Запуск

```powershell
pnpm infra:up; pnpm db:generate; pnpm db:migrate; pnpm db:seed
pnpm dev                                   # web :3000, admin :3001
pnpm --filter @dance/web worker            # фоновые задания
pnpm --filter @dance/db exec dotenv -e ../../.env -- tsx prisma/grant-role.ts <email> ADMIN
```

## Необязательные переменные окружения

| Назначение | Переменные |
| --- | --- |
| Google-вход | `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` |
| Web Push | `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` (`pnpm --filter @dance/web exec web-push generate-vapid-keys`) |
| Хранилище | `S3_ENDPOINT`, `S3_BUCKET`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `S3_PUBLIC_URL` |
| Instagram | `INSTAGRAM_OEMBED_TOKEN` (если Meta потребует токен) |
| Геокодер | `GEOCODER_URL`, `GEOCODER_USER_AGENT`, `PHOTON_URL` |
| Telegram | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, `TELEGRAM_BOT_USERNAME` |
| Крон по HTTP | `CRON_SECRET` |
| Ошибки | `SENTRY_DSN` (GlitchTip) |
| Админка | `ADMIN_URL`, `WEB_URL` |

Проверка воркера: `GET /api/health/worker` отвечает 503, если воркер не обновлял отметку в Redis дольше 90 секунд.
